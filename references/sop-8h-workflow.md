## The 7 steps, unpacked

### Step 1 — Target-school requirements (30 min)
- Extract PS word limit, CV emphasis (research vs. practice), recommender preference, school-specific prompts.
- Build a checklist before writing. **Differentiation rule:** research-oriented programmes weight research; professionally-oriented weight practice.

### Step 2 — Personal material inventory (60 min)
- Dump everything: transcript, papers, internship certs, competition awards, letters, project reports.
- Bucket into four categories: **academic background / practice experience / skills & certs / personal character**.
- Summarise each item in 1-2 sentences *before* filtering.

### Step 3 — Persona synthesis (30 min)
- Distill **1-2 core advantages** — not 5, not 10.
- **Tri-unity rule:** PS = story / CV = quantified outcomes / RL = recommender corroboration.

### Step 4 — PS framework + paragraphs (120 min)
- **Hook:** one *specific scene*, not a broad statement.
- **Three body paragraphs:** academic background / practice experience / career goal.
- **BAR model:** Background → Action → Result → Reflection.
- **Close:** name the programme's *specific* resources (faculty / labs / courses).
- Cross-reference: meta-framework's 10 beats.

### Step 5 — CV quantification + layout (60 min)
- Order: Education → Research → Internship → Skills.
- STAR + numbers. Delete HS experiences, irrelevant gigs. Each bullet ≤ 3 lines, ≤ 2 pages.
- Cross-reference: CV template rules R1-R3.

### Step 6 — RL recommendation + draft (60 min)
- Recommender priority: research advisor > core-course professor.
- Prep packet: PS + CV + transcript; flag abilities to highlight.
- RL draft: self-intro → 2 concrete cases → strong close. Send to recommender for confirmation.

### Step 7 — Full review + polish (60 min)
- Grammar / spelling / format.
- **Alignment check:** PS not CV-in-prose; RL not self-praise.
- **Traceability:** every claim must be real.

## 中文原稿（verbatim）

挑战8h写完文书初稿 1. 了解目标院校要求 先去官网扒下PS、CV、RL的具体要求，比如PS字数限制、CV要突出科研还是实践、RL推荐人偏好，把这些要求列成清单，避免后续跑偏。比如科研型专业就重点写科研经历，应用型专业就多放实践案例，精准适配才不白费功夫。 2. 梳理个人素材 打开空白文档，把本科成绩单、科研论文、实习证明、竞赛证书全部列举出来，按学术背景、实践经历、技能证书、个人特质分类整理。每类素材用一两句话概括内容，先找素材再筛选，避免遗漏亮点。 3. 确定文书整体人设 结合目标专业和素材，提炼1-2个核心优势，所有文书都围绕这个主线展开。PS里用故事串起经历，CV里用数据量化成果，RL里让推荐人佐证能力，三份文书形成三位一体的人设，不零散不重复。 4. 搭框架+填段落 PS按开头引题，主体展，-结尾表决心搭框架，开头用1个具体场景切入，主体分3段，分别讲学术背景、实践经历、职业目标，每段用背景，行动，结果，反思的模型，避免只堆经历没感悟；结尾提学校独特资源，体现精准匹配。 5. 做CV量化+排版 CV按教育背景，科研经历，实习经历，技能证书排序，教育背景标GPA和核心课程，科研和实习用STAR法则写，比如设计Python爬虫抓取10万条数据，构建模型准确率提升18%，所有成果都量化，删除高中经历和无关兼职，每段不超过3行，格式统一，2页以内搞定。 6. RL沟通要点+初稿 先定推荐人，优先选科研导师或专业课老师，提前整理PS+CV+成绩单发给他做参考，标注要突出的能力，比如希望老师突出我的数据分析能力。RL初稿按推荐人自我介绍，2个具体案例论证能力，强烈推荐来写，案例要细节化，避免空话，写完发给推荐人确认。 7. 整体校对+检查 最后通读文书，检查语法错误、拼写错误、格式统一，重点看有没有混淆文书定位，比如PS没写成CV加长版，RL有没有硬夸自己。再检查一遍语法，确保没有低级错误，确认所有经历真实可追溯，不虚构不夸大，大功告成
