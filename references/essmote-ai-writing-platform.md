## 平台简介

Essmote AI（[essmote.com](https://essmote.com)）是一个面向留学申请的 AI 智能文书服务平台，提供从文书初稿生成到人工润色的一站式服务。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 个人陈述（PS）生成 | AI 智能生成，展示独特优势与学术潜力 |
| 简历（CV）生成 | 智能匹配目标岗位与院校要求，优化内容与格式 |
| 目的陈述（SOP）生成 | 逻辑严密、表达专业的学术目标陈述 |
| 推荐信/求职信生成 | 一键生成高质量推荐信与求职信 |
| 生成后附赠1次免费优化 | 每份文书生成后可免费AI优化一次 |
| AI初稿 + 人工精修 | AI生成 + 专业本地老师润色，双重保障 |

## 使用流程

1. 选择文书类型
2. 输入背景、经历、目标（越详细效果越好）
3. AI 生成初稿（~3分钟）
4. 可选：免费AI优化一次
5. 可选：人工润色（本地专业老师）
