# AGENTS.md — Grad Apply & Overseas Career Skill

This repository is a reusable **graduate application & overseas career super skill**: a complete rule set, end-to-end workflow and command system for multi-discipline master's applications, overseas internships / jobs, and founder-track planning.

When the user works on anything related to studying abroad, overseas work, or founder visas, treat [`SKILL.md`](./SKILL.md) as the operating manual and follow it in full.

@SKILL.md

(If your agent tool does not auto-resolve the @-import above, read `SKILL.md` in full before starting work.)

## Key operating rules

- Save all deliverables (evidence map, CV / SOP drafts, gap-improvement plans, comparison tables) as local Markdown files with version records - never keep them only in chat.
- Never fabricate academic experience, project results, awards, internships, funding or traction; every claim must come from the user's real materials.
- The user retains final editing rights; do not overwrite their original sentences without explicit permission.
- Personal application materials (profile, transcripts, evidence map, CVs, SOPs, offer letters) are **private** - keep them under gitignored paths (see `.gitignore`) and never commit them to this public repository.
- Visa policy facts (SKILL.md Section 5.2) are an August-2026 snapshot; always re-check official immigration sources before any filing decision and recommend a licensed immigration lawyer.
- Slash commands such as `/profile-intake`, `/build-evidence-map`, `/school-match`, `/gap-improve-plan`, `/cv-generate`, `/sop-draft`, `/sop-review`, `/lor-template`, `/prof-email-draft`, `/deadline-timeline`, `/offer-compare`, `/visa-compare`, `/founder-deck` are workflow triggers defined in SKILL.md Section 3 - when the user types one, execute the corresponding workflow.
